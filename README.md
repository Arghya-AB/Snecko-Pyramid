# Dead Field Elimination

## Running

Run it with `make FOLDER=Testx` where x is the test number you want to run from `testcases`.

The output will be in the generated `sootOutput` folder along with the modified jimple files for reading.
To run the modified program, `java Test` inside `sootOutput`.
To run the original program, `java Test` inside the `testcases/Testx` folder
